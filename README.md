A selection of projects from my learning and development journey.

### 01. Aura AI — Multimodal AI Chatbot

[![Repository](https://img.shields.io/badge/GitHub-View_Repository-8A4FFF?style=for-the-badge&logo=github)](https://github.com/meet2shrishtichaudhary-svg/Multimodal-AI-chatbot)

A full-stack multimodal AI platform exploring intelligent conversations, document-based question answering and AI-powered tools.

- Generative AI and conversational interfaces.
- Retrieval-Augmented Generation (RAG).
- Document processing and semantic search.
- Long-term conversational memory.
- AI agent orchestration.

**Technologies:** Python, JavaScript, FastAPI, React, Gemini API, PostgreSQL.

---

### 02. Spam Message Classification

[![Repository](https://img.shields.io/badge/GitHub-View_Repository-8A4FFF?style=for-the-badge&logo=github)](https://github.com/meet2shrishtichaudhary-svg/Spam-Message-Classification)

An educational Machine Learning project that classifies SMS messages into Spam and Ham categories using Natural Language Processing.

**Key areas:**
- Text preprocessing and normalization.
- TF-IDF feature extraction.
- Naive Bayes and Logistic Regression.
- Model evaluation using F1-score.
- Interactive Streamlit application.

**Technologies:** Python, Pandas, Scikit-learn, NLTK, Streamlit.

---

### 03. Heart Risk Prediction System

[![Repository](https://img.shields.io/badge/GitHub-View_Repository-8A4FFF?style=for-the-badge&logo=github)](https://github.com/meet2shrishtichaudhary-svg/Heart-Risk-Prediction-System)

An educational Machine Learning application exploring cardiovascular risk prediction using clinical dataset features.

**Key areas:**
- Data preprocessing.
- Feature engineering.
- Classification algorithms.
- Model evaluation and cross-validation.
- Interactive prediction interface.

**Technologies:** Python, Pandas, Scikit-learn, Streamlit.

*Educational project only; predictions are not medical diagnoses.*
